# Calculadora con onclick

Calculadora web hecha con HTML, CSS y JavaScript. Es una práctica para manejar eventos con el atributo `onclick` en el HTML.

**Demo:** https://juanmur444-lang.github.io/calculadora-onclick/

Práctica académica del Tecnólogo en Análisis y Desarrollo de Software (ADSO), SENA.

## Funcionalidades

- Suma, resta, multiplicación y división.
- Decimales (no deja escribir dos puntos en el mismo número).
- No deja poner dos operadores seguidos ni empezar con un operador.
- **%** convierte el último número en porcentaje.
- **C** borra todo y **←** borra el último carácter.
- Muestra **Error** si la operación no es válida, por ejemplo una división por cero.

## Tecnologías

- HTML
- CSS
- JavaScript (sin librerías)

## Cómo ejecutarlo

Ábrela en la [demo](https://juanmur444-lang.github.io/calculadora-onclick/), o descarga el repositorio y abre `index.html` en el navegador:

```
git clone https://github.com/juanmur444-lang/calculadora-onclick.git
```

## Qué aprendí

- Conectar botones con funciones usando `onclick`.
- Validar la entrada del usuario antes de calcular.
- Manejar errores con `try` y `catch`.
